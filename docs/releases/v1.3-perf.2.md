# Realistic Water Performance Fork 1.3-perf.2

**Modified, unofficial fork of [Realistic Water](https://github.com/sskaffy/Realistic-Water) by Skaffy.** For Minecraft 26.3 (Fabric).

## Highlights
- New tabbed control panel that replaces the old settings list (K, `/waterpanel`, `/water gui`).
- Ocean preset and experimental "realistic world" game rules.
- Auto FPS no longer makes water vanish mid-flood.
- Big floods on the Quality preset no longer switch the simulation off.

## Downloads
| Jar | Starting defaults |
|---|---|
| `realistic-water-1.3-tsunami.jar` | Recommended |
| `realistic-water-1.3-lowend.jar` | Lightest |
| `realistic-water-1.3-balanced.jar` | Finer water with foam |

Replace the original Realistic Water jar; don't install both.
